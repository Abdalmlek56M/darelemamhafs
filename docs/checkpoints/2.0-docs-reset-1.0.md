- `deploy/update.sh` (جديد، 588 سطرًا) — preflight → **backup إلزامي** → git pull --ff-only → build/publish → migrate → تحقق عدد migrations → swap → smoke سبع نقاط → **rollback تلقائي للبيناريز** عند الفشل → retention/logs/state. يدعم `--dry-run` و`--skip-build` و`--allow-stopped-services`.

- `deploy/preflight.sh` (جديد) — 15+ فحصًا read-only بتقرير PASS/WARN/FAIL.
- `deploy/scripts/dar-backup.sh` — manifest JSON + SHA-256 + `pg_restore --list` (TOC) + التحقق من النسخة البعيدة + flock + retention 30 يوم + OnFailure.
- `deploy/scripts/dar-healthcheck.sh` + `systemd/dar-healthcheck.{service,timer}` — services/health/disk/backup age/TLS/nginx، كل 6 ساعات.
