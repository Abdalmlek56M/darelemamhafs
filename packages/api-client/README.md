# @dar/api-client

Generated TypeScript client for the Dar .NET API.

- Contract: `openapi.v1.json` (OpenAPI 3.1, generated from the .NET API).
- Types: `src/schema.d.ts` (generated by `openapi-typescript`).
- Runtime: `src/client.ts` (`openapi-fetch`).

## Regenerate

```bash
npm run generate
```

Never hand-write request/response types. If the contract changes, regenerate and commit both files.

## Usage

```ts
import { api } from "@dar/api-client";

const { data, error } = await api.GET("/api/v1/students", {
  params: { query: { page: 1, pageSize: 25 } }
});
```
